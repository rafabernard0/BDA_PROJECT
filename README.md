## 📌 Project Description

This project explores and analyzes the NYC Yellow Taxi dataset (2022–2024) using a wide set of data mining and advanced analytics techniques. The analysis covers exploratory data analysis, data preprocessing, clustering, forecasting, price prediction, and graph-based analysis, concluding with a comprehensive report and visualizations.

---

## 📁 Repository Structure

| Notebook                         | Description                                                                |
|----------------------------------|----------------------------------------------------------------------------|
| `01_EDA.ipynb`                   | Initial exploratory data analysis: data types, distributions, insights     |
| `02_DATA_CLEANING.ipynb`         | Preprocessing pipeline: missing values, type corrections, feature cleanup  |
| `03_CLUSTERING.ipynb`            | Clustering analysis using K-Means and DBSCAN, dimensionality reduction     |
| `04_FORECAST.ipynb`              | Time series forecasting using historical demand patterns                   |
| `05_PRICE_PREDICTION.ipynb`      | Price prediction models using regression techniques                        |
| `06_GRAPH_ANALYSIS.ipynb`        | Graph analytics with GraphFrames: influencer and connection detection      |

- T-SNE & PCA for dimensionality reduction
- Git & GitHub for version control

---

## 📊 Key Results

- Cluster separation improved significantly with DBSCAN + t-SNE (see final report)
- Forecasting models captured seasonal and hourly demand spikes
- Linear regression models performed well in estimating trip price
- Graph algorithms (e.g., PageRank) identified key pickup/drop-off hubs
